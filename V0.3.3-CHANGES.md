# Aviation Passport V0.3.3

- Work Rights EU shortcut moved into the country selector.
- Country selectors now show normal country names only; ISO-2 codes remain internal.
- Aircraft family selectors are grouped into logical manufacturer blocks.
- Environment options have an explicit logical order.
- Aircraft exposure now uses Start / End plus a Current Exposure checkbox.
- Removed Last Worked On from the exposure workflow.
- Removed Short Description from Employment.
- Added Edit / Remove for licences.
- Added Edit / Remove for aircraft ratings.
- Editing a verified licence or rating automatically returns it to pending verification through the existing database trust triggers.
- Replacing/removing a licence or rating cleans up its private evidence file where possible.
